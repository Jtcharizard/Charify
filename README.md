# Charify

Charify é um companion Android para o YouTube Music: mantém o YouTube Music como motor de reprodução e oferece uma interface própria para controle, busca, favoritos, histórico, playlists locais e temas.

## v0.5.0 Stable

- UI reconstruída em layout XML nativo
- conteúdo central sempre `match_parent`
- navegação inferior persistente
- retrato e paisagem
- 5 temas com wallpaper
- player e mini-player
- controle da sessão ativa do YouTube Music
- busca pela YouTube Data API v3
- favoritos, histórico e playlists locais

> O Charify não extrai nem baixa streams do YouTube Music. A reprodução continua sendo feita pelo app oficial.
